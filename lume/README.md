# LUME — Ristorante italiano contemporaneo

**LUME è un progetto dimostrativo di portfolio.** Il ristorante, il menu, i prezzi, gli orari e la località sono inventati a scopo di esercizio. Non esiste un'attività reale e il modulo prenotazioni non invia né salva dati.

## Struttura

- `index.html` — contenuti e struttura semantica
- `style.css` — identità visiva e layout responsive
- `script.js` — selettore IT/EN, categorie del menu, navigazione mobile e messaggio del modulo demo

Realizzato con HTML, CSS e JavaScript vanilla. Nessun framework o dipendenza di build.
